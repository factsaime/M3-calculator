# Калькулятор M3

Калькулятор в стиле Material 3, написанный как одна веб-страница и упакованный
в три приложения: Android, Windows и Linux.

Вся логика живёт в одном файле — `app/src/main/assets/index.html`. Обёртки
только показывают его во встроенном браузере, поэтому интерфейс везде одинаковый.

## Что умеет

- Обычные операции, проценты, факториал, память (MC / MR / M+ / M−)
- Научный режим: тригонометрия и обратные к ней, гиперболические, логарифмы,
  степени, корни, `nCr` / `nPr` / НОД / НОК
- График: несколько функций одновременно, масштаб, перетаскивание, точки
  пересечения, PNG, таблица значений, координаты по `x` и `y`
- Производная и интеграл (численно), касательная на графике
- Квадратное уравнение, системы двух уравнений, точные дроби
- Кредит и вклад, статистика по набору чисел
- Единицы измерения и системы счисления
- Физические константы с поиском
- Оформление: 4 темы, форма кнопок, цвет каждой группы, перестановка кнопок
- Режим экзамена: прячет историю и подсказки

## Структура

```
app/src/main/assets/index.html        весь калькулятор: разметка, стили, логика
app/src/main/java/.../MainActivity.java  WebView-обёртка и мост Android.save()
app/src/main/res/…                    тема, цвета, иконка-вектор
desktop/main.js                       Electron-обёртка
desktop/package.json                  сборка .exe и .AppImage
desktop/tools/make-icon.js            генератор PNG-иконки без зависимостей
.github/workflows/build-apk.yml       сборка APK и публикация в Releases
.github/workflows/build-desktop.yml   сборка Windows и Linux версий
```

## Готовые сборки

**Android.** Каждый пуш в `main` собирает APK и публикует его в
[Releases](../../releases) как `app-debug.apk`. Подпись отладочная — для
установки на свой телефон этого достаточно, в Google Play с такой не пустят.

**Windows и Linux.** Воркфлоу `Build Desktop` собирает установщик `.exe`
и `.AppImage`, они лежат в Artifacts последнего запуска на вкладке
[Actions](../../actions).

## Как править

Поменяй `app/src/main/assets/index.html` — при следующем пуше пересоберутся все
три платформы. Десктопная сборка запускается, когда меняется сама страница или
папка `desktop/`.

Название приложения — `android:label` в `AndroidManifest.xml` и `productName`
в `desktop/package.json`. Идентификатор пакета и версия — в
`app/build.gradle.kts`.

## Иконка

Для Android нарисована вектором (`app/src/main/res/drawable/ic_launcher.xml`) —
масштабируется без потерь. Для десктопа `desktop/tools/make-icon.js` считает
PNG 512×512 прямо в пикселях через `zlib` из Node, без ImageMagick и SVG-
рендереров; `.ico` для Windows electron-builder делает из этого PNG сам.

## Технические детали

- Android: `minSdk 24`, `targetSdk 34`, AGP 8.5.2, Gradle 8.9, JDK 17
- Страница грузится через `https://calc.local/`, а не `file://` — иначе в WebView
  не работают `localStorage`, история переходов и буфер обмена
- Кнопки «В файл» и «PNG» на Android идут через `Android.save()` в общую папку
  «Загрузки»; на десктопе — обычным скачиванием Chromium
- Кнопка «Назад» на Android закрывает открытый диалог, а не приложение
- Данные (тема, история, раскладка кнопок, состояние) хранятся локально,
  ничего никуда не отправляется
